## What this repo is

A personal Android app store. Apps built by the user or Claude are distributed via this GitHub repo. The Android client app (`store-app/`) reads `catalog.json` from GitHub and handles downloading and installing APKs on-device.

## Build commands

All Gradle commands run from `store-app/`:

```bash
# Debug build (installable APK)
./gradlew assembleDebug

# Release build (requires signing config)
./gradlew assembleRelease

# Install directly to connected device
./gradlew installDebug

# Lint
./gradlew lint

# Run unit tests
./gradlew test
```

The Gradle wrapper (`gradlew`) is generated by Android Studio on first sync — run commands from inside `store-app/` after Android Studio has synced the project at least once.

## Architecture

**Two concerns live in this repo:**

1. **`catalog.json`** (repo root) — the app index, served via `raw.githubusercontent.com`. Edit this to add/update/remove apps. The Android client fetches it at runtime.

2. **`store-app/`** — the Android client app (Kotlin + Jetpack Compose, package `com.personal.appstore`).

**Data flow:** `StoreViewModel` → `CatalogRepository` (Ktor HTTP GET) → parses `AppCatalog` / `AppEntry` models → UI screens via `StateFlow<UiState>`.

**Install flow:** `StoreViewModel.installApp()` → `ApkInstaller.downloadAndInstall()` downloads the APK to `cacheDir`, then triggers Android's system installer via `FileProvider` + `Intent.ACTION_VIEW`.

**Navigation:** Single-activity, Compose Navigation with three destinations: `list`, `detail`, `settings`. `AppEntry` is passed between list→detail via `savedStateHandle` (it's `@Parcelize`).

**Catalog URL** is persisted in `SharedPreferences` via `PreferencesRepository`. The hardcoded default points to `raw.githubusercontent.com/honkers556/personal-app-store/main/catalog.json`. Users can override it in the Settings screen.

## Adding an app to the catalog

Edit `catalog.json` at the repo root, add an entry to the `apps` array, then commit and push. APKs are hosted as GitHub Release assets — upload the APK to a new Release, copy the asset download URL into `apk_url`.

```json
{
  "id": "com.example.myapp",
  "name": "My App",
  "description": "What it does",
  "version_name": "1.0.0",
  "version_code": 1,
  "apk_url": "https://github.com/honkers556/personal-app-store/releases/download/TAG/app.apk",
  "icon_url": "https://raw.githubusercontent.com/honkers556/personal-app-store/main/icons/myapp.png",
  "category": "Utilities",
  "changelog": "Initial release",
  "size_bytes": 2048000
}
```

Icons go in `icons/` at the repo root.

## Key files

| File | Purpose |
|---|---|
| `catalog.json` | App index — edit to publish apps |
| `store-app/app/src/main/java/com/personal/appstore/data/PreferencesRepository.kt` | Default catalog URL lives here |
| `store-app/app/src/main/java/com/personal/appstore/data/model/AppEntry.kt` | Catalog JSON schema (Kotlin models) |
| `store-app/app/src/main/java/com/personal/appstore/ui/StoreViewModel.kt` | All business logic |
| `store-app/app/src/main/java/com/personal/appstore/install/ApkInstaller.kt` | APK download + install |
| `store-app/gradle/libs.versions.toml` | All dependency versions |

## Tech stack

- Kotlin 2.1, AGP 8.8.2, compileSdk 35, minSdk 26
- Jetpack Compose (BOM 2025.01.01), Material 3, Navigation Compose
- Ktor 3.1.1 (HTTP client, Android engine)
- Coil 3.1.0 (image loading, Ktor network backend)
- `kotlinx.serialization` for JSON, `kotlin-parcelize` for nav arg passing
